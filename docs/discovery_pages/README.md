# Quilla · paquete de Pages para Discovery

Este directorio contiene fuentes en español para crear Pages gobernadas con
`Discover > Pages > Create page > Genie Code > Bulk import pages`.

## Orden recomendado

1. Importe `00_quilla.md` en el dominio `Quilla Quilla`.
2. Importe cada archivo restante dentro del subdominio indicado en su nombre.
3. Revise los Pages propuestos y conserve los títulos, sinónimos y definiciones.
4. En cada draft, convierta los nombres de objetos listados en `Related assets`
   y `Sources` en vínculos reales usando el selector de activos o `@`.
5. Publique los Pages solamente después de verificar sus fuentes relacionadas.

## Controles

- No copie PII, nombres de clientes, documentos, correos ni teléfonos.
- No presente datos sintéticos como información financiera real.
- Mantenga separados hechos, inferencias y recomendaciones.
- Una recomendación de IA nunca equivale a una decisión automática.
- Use español como idioma principal y sinónimos PT/ES/EN para la experiencia
  bilingüe de Quilla.
